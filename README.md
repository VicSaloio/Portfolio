# Portfólio

Portfólio pessoal desenvolvido para apresentar minha trajetória, projetos e formas de contato.

O site foi construído com foco em organização visual, responsividade e navegação simples.

## Funcionalidades

- Página inicial em formato de landing page
- Seção de apresentação
- Exibição de projetos
- Área de contato
- Navegação entre páginas/seções
- Layout responsivo

## Tecnologias utilizadas

- HTML
- CSS
- Mobile First
- Git
- GitHub

## Acesso ao projeto

O portfólio está publicado através do GitHub Pages:

https://vicsaloio.github.io/Portfolio/

## Objetivo do projeto

Projeto desenvolvido para praticar conceitos de desenvolvimento front-end, estruturação de páginas, estilização com CSS, responsividade e publicação de projetos na web.
